KSA PANEL WEBSITE — QUICK START

Files:
- index.html : website content
- style.css  : design and responsive layout
- script.js  : mobile menu and current year

HOW TO USE:
1. Extract ksa-panel-website.zip.
2. Open index.html in Chrome to preview the website.
3. To publish with GitHub Pages:
   a. Create a GitHub repository named ksa-panel.
   b. Upload index.html, style.css, script.js, and README.txt to the repository root.
   c. Open Settings > Pages.
   d. Under Build and deployment, choose "Deploy from a branch".
   e. Choose branch "main" and folder "/ (root)", then Save.
   f. Wait for GitHub Pages to publish the site.
